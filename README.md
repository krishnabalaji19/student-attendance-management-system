# Student Attendance Management System

A full stack web app where teachers mark student attendance and students view their own records.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: SQLite
- Auth: JWT

## Setup

Backend:

```bash
cd backend
npm install
npm start
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
